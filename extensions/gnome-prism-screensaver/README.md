# GNOME Prism Screensaver

A GNOME Shell extension that plays a user-selected looping video on GNOME's
real lock screen, forked from
[Live Lock Screen](https://github.com/nick-redwill/LiveLockScreen) (AGPL-3.0
— see `LICENSE.txt` and `NOTICE.md` in this directory).

This is an optional GNOME Prism feature. For installation, configuration,
dependency, and troubleshooting instructions, see the "Screensaver (optional)"
section of the main [GNOME Prism README](../../README.md).
